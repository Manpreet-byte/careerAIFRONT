# Bellavue Atelier Frontend

A React + Vite luxury leather handbag and accessories frontend inspired by quiet luxury, Italian craftsmanship, and premium editorial fashion.

## Stack

- React
- Vite
- Tailwind CSS v4
- Framer Motion
- React Router
- Lucide Icons

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
